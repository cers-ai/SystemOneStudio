## CPU CLI 使用

```powershell
uv run python -m son_data_pipeline.decision_cli --dataset <种子.csv> --schema <schema.json> --mapping <mapping.json> --output <新的输出目录>
```

schema 使用用户 V3 第 5 节对象，含 schema_id/type/version/question/三个 options。mapping 是数组，每个 CSV 列恰好一个角色：STATE_INPUT、TARGET_CHOICE、EVIDENCE、GROUP_ID、ENTITY_ID、IGNORE。STATE_INPUT 可附 value_type，默认 TEXT；数值必须显式选 NUMBER。当前 CLI 标签使用 black/white/gray；导入函数支持调用方提供明确别名映射，尚未接 UI。

无 group/entity 时需 `--independent-rows`；小数据共享模式需 `--mode shared_valid_cal`。既有输出目录会报错，不覆盖。CLI 不进行训练。
