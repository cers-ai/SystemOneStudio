# SystemOneStudio

面向业务人员的决策模型训练工作台。目标是通过 Web 七步沉浸工作台，让用户定义场景、上传种子、合成数据、选择模型与训练方式、训练验证并导出部署。首版推荐在一台 Linux GPU 服务器一体部署，浏览器不与 Windows 绑定。

**当前尚未完成产品闭环。** 本轮审计证实：上传请求、标签映射、任务状态存在断点；Worker 尚未将版本登记、评测和部署接入主链，真实业务预测接口缺失。模块代码与本地测试通过不能代替真实 GPU 和浏览器验收。

## 开发与检查

```powershell
# 依赖首次安装/变更时
npm install
uv sync --all-packages

# 本地开发，两条命令分别在终端运行
npm run dev:api
npm run dev

# 改动后的完整检查
npm run verify
npm run build
npm run verify:py

# 契约/API 变更后，验证前生成
uv run python tools/gen_openapi_types.py
```

API 默认 `9969`、Web 开发默认 `5174`。`npm run up` 是现有本地 web/api compose 入口，**不能当作远程 GPU 全链路启动命令**。当前 GPU 镜像和 Worker 启动配置存在待修复项，见审计；新版启动说明随实现和真实环境验收交付。

## 核心约束

三分类；每条输出必须有依据；合成数据不得进入测试集；固定 seed 划分 7:1.5:1.5；JEV 双开关独立；默认 Q4_K_M；性能指标优先；版本血缘可追溯；界面只用业务文案；未知/未测量不得冒充成功。

本阶段拟交付用户自定义场景、七步开放工作台、同族轻量模型与已验证训练方式、一体部署、模型/工作区导出恢复。业务模板与智能助手延期，分机轻代理保留接口后续再做。人工构造示例只能证明流程，不能证明真实业务效果。
